# Lab 7 — Image Segmentation and Feature Extraction

This lab demonstrates edge detection, corner detection, and image segmentation using Python and OpenCV.

## Course
ARTI407 — Image Processing  
Imam Abdulrahman Bin Faisal University

## Tasks
1. **Canny Edge Detection:** Detect edges in the camera image and display the original and edge images.
2. **Harris Corner Detection:** Detect corners in a checkerboard image and highlight them with red dots.
3. **Otsu's Thresholding:** Automatically select a threshold and display the original image, its histogram, and the binary image.

## Assessment Result
Otsu's method selected a threshold of **107** for the sample coins image.

## Libraries Used
- OpenCV
- NumPy
- Matplotlib
- scikit-image

## How to Run
Open the notebook in Jupyter Notebook or JupyterLab and run the cells from top to bottom.
